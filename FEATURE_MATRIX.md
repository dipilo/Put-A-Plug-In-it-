## Notes

- **SophisticatedCore ItemStackKey cache clearing** - Clears on the client every N ticks above a size threshold; the server-tick clear is opt-in. Self-disables against SophisticatedCore 1.4.6.1504+, which fixed it upstream.
- **EntityTickList passive-map clear** - The only injector in the tree without require = 0, so it must bind everywhere it is applied. Its two targets are byte-identical across the whole range.
- **LivingEntity last-damage-source expiry** - Vanilla keeps lastDamageSource until something reads it, so a mob hurt once pins its attacker and that attacker's level for life. Upstream relies on the getter clearing the field; 26.3 refactored it to stop doing so, so the write is explicit here and no version gate is needed. Runs per living entity per tick, guarded by a null check.
- **Biome temperature cache sharing** - Redirects Biome's per-instance temperature ThreadLocal onto one shared instance.
- **LivingEntity brain-memory clear on unload** - Driven by an entity-unload hook: Fabric ServerEntityEvents.ENTITY_UNLOAD, Forge EntityLeaveLevelEvent on server levels (gated >=1.19 - Forge 40 still calls it EntityLeaveWorldEvent). NeoForge starts above the affected window. Vanilla fixed this itself in 1.19.4. Disables itself when MemoryLeakFix is installed.
- **TagKey weak intern pool** - Swaps TagKey's strong interner for a weak one by reflection. Self-gates to exactly 1.18.2, so the island copy can never fire on the versions the island covers.
- **Crosshair target / hit result reset** - Probes the mojmap, SRG and intermediary field names, because only NeoForge (and Fabric from 26.x) runs mojmap. Clears only while out of a level: GameRenderer#pick rewrites both fields every in-world tick, so an in-world clear frees nothing and only hands a null to mods reading hitResult from the same end-of-tick hook (it was breaking Create's super-glue right-click).
- **Huge-screenshot buffer free-on-failure** - grabHugeScreenshot was removed with the 1.21.5 render overhaul, taking GlUtil with it. Gated out at build time from 1.21.5 so no dead injector is compiled in, with the PapiMixinConfigPlugin check kept as defence.
- **Texture read-buffer free-on-failure** - 1.19.4 split readResource and wrapped the read in vanilla's own memFree-on-IOException handler, so the leak ends there.
- **Drowned navigation cleanup (MC-202246)** - Island only: the bug is below the Stonecutter tree's 1.18.2 floor. A Drowned that swaps navigation on entering water strands the instance registered at spawn in the level's navigation set.
- **ModelManager cache cleanup on client world leave** - Detects the in-world to main-menu transition on the client tick and clears large baked-model maps; the BlockState-to-id map is opt-in.
- **ImmediatelyFast compatibility auto-patching** - Rewrites immediatelyfast.json: disables experimental_screen_batching when MemoryLeakFix is present or an Intel GPU is detected, and avoid_redundant_framebuffer_switching on Intel.
- **/papi leak diagnostics** - /papi leak report writes a heap/GC/watched-size/client-model report; /papi leak dumpHeap is opt-in because it freezes the game. Permission level 2.
- **Iceberg: clear EntityCollector and CustomItemRenderer caches** - Fields are resolved individually, so older Iceberg builds simply clear fewer of them.
- **JEI: clear RecipeTransferManager, Grindstone menu and ingredient codecs** - The transfer manager is resolved per call through the live JEI runtime, which is replaced across world loads. Upstream drops the grindstone menu on respawn and logout; level unload stands in for the latter. The TypedIngredientCodecs statics each close over the IIngredientManager of the runtime that built them and are lazily rebuilt, so dropping them is safe; each field is resolved individually, so a JEI that renamed one still clears the rest.
- **SophisticatedCore: invalidate StorageWrapperRepository on world unload** - Upstream clears the repository on server start/stop, which covers singleplayer; a client leaving a dedicated server runs neither, and Guava's expireAfterAccess only evicts on a later cache operation.
- **SophisticatedCore: reset the CraftingTweaks UI part on world change** - Only acts when CraftingTweaks is installed too: the compat class ships only in that build of SophisticatedCore, and its singleton pins the storage screen, menu, player and level you left.
- **Supplementaries: run cache clearers on server stop** - Upstream's three version-gated classes collapse into one table, since an absent method is skipped.
- **ETF: release player-texture state on respawn** - Re-points the cached texture at the new player on ETF 7.x and clears the map on 6.x, chosen by field presence rather than version parsing.
- **EMF / ETF: drop renderer state after each render** - The one PAPI injection in a per-entity, per-frame path, so the config plugin skips the mixin unless EMF or ETF is installed. Gated at >=1.21.9 to LivingEntityRenderer#submit, which is what #render was renamed to.
